# Sistema de Reproducción de Audiencias - Frontend

Este proyecto es el frontend para el Sistema de Reproducción de Audiencias, que proporciona una interfaz de usuario para buscar, visualizar y gestionar archivos multimedia.

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API para comunicación con el backend

## Configuración

Para visualizar el frontend, simplemente abre el archivo `index.html` en un navegador moderno.

## Características

- Búsqueda de archivos y carpetas.
- Reproducción de archivos multimedia, con soporte para conversión de formatos no compatibles.
- Visualización de notificaciones y progreso de operaciones.

## Personalización

Puedes personalizar el estilo y comportamiento del frontend modificando los archivos CSS y JavaScript según tus necesidades.
